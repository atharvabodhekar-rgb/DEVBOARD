# AI Declaration

This project, DevBoard, was developed with AI assistance.

AI tools used or referenced during the development workflow include:

* ChatGPT
* GitHub Copilot
* Cursor AI

AI assistance was used for understanding requirements, planning the project structure, debugging React/TypeScript/Cloudflare issues, improving UI design, writing documentation drafts, and preparing deployment steps.

The final source code was reviewed, tested, edited, deployed, and verified manually by the developer. AI was used as a coding and debugging assistant, not as a replacement for understanding the project.

All generated suggestions were checked and adapted before being included in the final project.
