```text
Help me build a real-time collaborative whiteboard project like Figma-lite / Miro with infinite canvas, drawing tools, sticky notes, text, image upload, cursor presence, shareable links, view/edit permissions, undo/redo, auto-save, and WebSocket sync.
```

Explain the architecture for a real-time collaborative whiteboard using React, tldraw, Cloudflare Workers, Durable Objects, WebSockets, and room-based board links.
